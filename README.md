# ScopeBot

ScopeBot is a web app where teammates and customers chat with a Claude-powered AI product manager to scope feature requests, then track those requests on a kanban board. Admins see every request across the company along with the full AI-generated requirements doc, and can route planned work to an agent orchestrator (Paperclip), an external dev agent (Claude Code / Cursor), or a Notion board for human engineers.

## Features

- **AI scoping chat** — users describe a feature; the AI PM asks about problem, solution, benefits, and current cost/pain. Supports image, PDF, spreadsheet, and doc attachments.
- **Requirements docs** — "Finalize requirements" turns a conversation into a structured feature request with a full Markdown scope, exportable as PDF or Markdown.
- **Kanban tracking** — personal board (Requested → Planned → In Progress → Deployed) plus an admin board across all users.
- **Engineering routing** — planned requests go to an agentic team (Paperclip + a pull-based integration API) or to human engineers (Notion), with status synced back.
- **Email notifications** — verification, password reset, status changes, and admin/requester back-and-forth, via Resend.

## Stack

- pnpm workspaces, Node.js 24, TypeScript
- API: Express 5, cookie + Postgres session auth, `@anthropic-ai/sdk`
- Web: React 19 + Vite + Tailwind v4, wouter, React Query hooks generated by Orval from `lib/api-spec/openapi.yaml`
- DB: PostgreSQL + Drizzle ORM

## Getting started

```sh
pnpm install
pnpm --filter @workspace/db run push      # push schema to your Postgres DB
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/product-requests run dev
```

Other useful commands:

- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas after editing the OpenAPI spec

## Environment variables

### Required

| Variable | Description |
| --- | --- |
| `DATABASE_URL` | PostgreSQL connection string |
| `ANTHROPIC_API_KEY` | Anthropic API key for the AI product manager |
| `SESSION_SECRET` | Secret used to sign session cookies |

### Recommended

| Variable | Description |
| --- | --- |
| `ADMIN_EMAILS` | Comma-separated list of bootstrap admin emails. Seeded into the team only when the `team_members` table is empty (first run); after that, manage roles in Team Settings. Admin notification recipients come from the `team_members` table, supplemented by this list. |
| `INTERNAL_DOMAINS` | Comma-separated list of your company's email domains (e.g. `example.com`). Users on these domains are excluded from the Customers view. |
| `PUBLIC_APP_URL` | Canonical public origin used in outbound email links (verification, reset, request links). Falls back to `REPLIT_DOMAINS[0]`, then `http://localhost`. |

### Optional integrations

| Variable | Description |
| --- | --- |
| `INTEGRATION_API_TOKEN` | Bearer token for the external dev-agent API at `/api/integrations/*`. Endpoints return 503 if unset. |
| `PAPERCLIP_URL`, `COMPANY_ID`, `PAPERCLIP_API_KEY` | All three required to enable the Paperclip orchestrator integration. If any are missing, the Paperclip schedulers don't start and the Engineering Space UI shows "not configured". |
| `PAPERCLIP_ASSIGNEE_AGENT_ID` | Optional default agent to assign new Paperclip issues to. If unset, issues are created unassigned. |
| `NOTION_DATABASE_ID` | Notion database ID for human-routed engineering tickets. If unset, the Notion schedulers don't start. Notion and email (Resend) auth are provided via Replit-managed connectors when running on Replit. |
